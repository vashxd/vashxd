- 💼 **Software Developer at SEMSA Manaus** (Municipal Health Department). I work on a telehealth platform that connects primary care units with medical specialists, built with **Laravel 12, Vue 3, Inertia.js and PostgreSQL**.
- 🧪 **QA background** in manual and automated testing on agile teams, often with little documentation and fast-changing requirements.
- 🎮 **Game developer** on the side: real-time multiplayer party games for the browser and casual mobile games in Flutter.
- 🎯 **Open to** international opportunities in software development or QA.

## What I do

### 💻 Development
- **Backend:** PHP (Laravel), Node.js, REST APIs, MVC architecture
- **Frontend:** Vue 3, React, TypeScript, Tailwind CSS
- **Mobile:** Flutter / Dart
- **Databases:** PostgreSQL, MongoDB, including query optimization and indexing
- **Integrations:** third-party APIs, authentication services, data imports

### 🧪 Quality Assurance
- Test planning and test case design, including **BDD (Gherkin)**
- Functional, regression and exploratory testing
- End-to-end automation with **Cypress**
- API testing with **Postman**
- Test management and evidence in **Jira** and **Qase**

### 🎮 Game Development
- Real-time multiplayer with **Socket.io** (host screen + phones as controllers)
- Mobile games in **Flutter**, offline-first, with ad-based monetization
- Game design documents, core loop design and playtesting
