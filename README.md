## Games

Nine Android games built in **Unity 6 / C#**, all sharing the same architecture: pure C# simulation, scenes built entirely in code, automated tests and scripted builds.

| Game | Genre | Technical highlights |
|---|---|---|
| **Dobre** | Isometric action roguelite, dark fantasy | 3 regions, 21 rooms and bosses, character passives, meta-progression, NPC dialogue. Custom iris-transition shader, Python art pipeline (FBX → GLB) |
| **Lâmina do Crepúsculo** | 2.5D hack'n'slash | URP 2D, new Input System, Unity IAP. 3-axis combat (X, depth, jump), combos, perfect dodge, multi-phase bosses, Tower and Boss Arena modes |
| **Correio Voador** | Low-poly 3D endless runner | Segment-based level generator, 3 lanes, gliding and card throwing, missions, collection album, save system, custom shaders, bot player |
| **Tutano** | Survivors-like | Structural simulation: load-bearing pillars, collapses and falling physics. Floating joystick, Blender-scripted low-poly models |
| **Traço** | Physics drawing puzzle | Player strokes become physics bodies (RDP simplification + BoxCollider2D chains). 80 levels generated by an editor tool, limited ink, medals |
| **Estopim** | Logic and timing puzzle | Deterministic discrete simulation over a directed graph, campaign generator with 120 machines, per-piece error diagnosis |
| **Fôlego** | Solo 3D extraction in shipwrecks | Playable prototype, Blender/Python asset import pipeline, custom shaders |
| **Toco a Toco** | Balance runner | Accelerometer controls (tilt to aim, charge the jump), inverted-pendulum physics, shader-based water and sky |
| **Guerra de Turing** | Simultaneous-turn strategy vs. AI | Play against an LLM using your own API key (Claude, Gemini, OpenRouter). Per-model personas, an AI "learning notebook", automated match simulations |
